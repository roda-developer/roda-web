# Roda web — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir la web one-page de Roda: una historia cinematográfica con scroll, 4 preguntas opcionales y un final que arma "el tráiler de tu web" con WhatsApp precargado.

**Architecture:** Astro 5 genera HTML estático. Cada sección del guion es un componente `.astro` en `src/sections/`. Lo interactivo (preguntas, control deslizante, final) son islas React que comparten un store de nanostores. El copy vive en `src/content/`. GSAP ScrollTrigger + Lenis manejan la coreografía desde un único módulo cliente (`src/motion/`). La intensidad elegida se expone como la variable CSS `--intensidad` en `:root`.

**Tech Stack:** Astro 5, React 19, Tailwind v4 (`@tailwindcss/vite`), GSAP 3 + ScrollTrigger, Lenis, nanostores + @nanostores/react, Vitest, Playwright (con el Chrome del sistema, `channel: 'chrome'`, sin descargar navegadores).

**Spec:** `docs/superpowers/specs/2026-09-30-roda-web-design.md`

## Global Constraints

- Mobile first: CSS base = 390 px; breakpoints solo `min-width` (`md:` 768, `lg:` 1024, `xl:` 1280). Todo contenido existe en mobile.
- Copy en español rioplatense (voseo), sin jerga técnica ("SEO", "responsive", "performance" prohibidos en copy visible).
- Paleta base: `#0A0A0B` (sala), `#EDEAE4` (pantalla), `#E8A33D` (tungsteno). Technicolor: `#FF2E4D`, `#FFD400`, `#2B4BFF`, `#00C46A`, `#FF6FD8`, solo en Technicolor y en el extremo "grita".
- Tipos: Instrument Serif (títulos), Instrument Sans Variable (lectura/UI), Bricolage Grotesque Variable (solo Technicolor / intensidad alta).
- Nada literal de cine viejo: sin cuenta regresiva, claqueta, grano de película, letterbox.
- Easing de salida lento, nada elástico; fundidos 800–1200 ms; duraciones múltiplos de 1/24 s (`F = 1/24`).
- Sin JS o con `prefers-reduced-motion: reduce`: todo el contenido visible y en orden; animaciones → fundidos o nada.
- Respuestas solo en el navegador (`sessionStorage` dentro de try/catch); nada se envía a un servidor.
- Botones táctiles ≥ 44 px; contraste AA en texto de lectura.
- Loader máximo 2.5 s, nunca bloquea el contenido si JS falla.
- Proyectos solo reales; mientras no haya, la sección muestra el caso Heacky marcado como ejemplo en `proyectos.ts` (con `ejemplo: true`) y un TODO de contenido en el README, no en la UI.
- Contacto: `WHATSAPP` y `MAIL` en `src/content/contacto.ts`, con valores placeholder marcados para reemplazar.

## Review Focus

1. Visitante que no responde ninguna pregunta: el final debe mostrar "¿Cuál es tu historia?" con link de WhatsApp genérico, sin "undefined" ni huecos en la sinopsis.
2. Visitante que responde algunas preguntas (p. ej. solo rubro): la sinopsis debe omitir las cláusulas faltantes y seguir siendo gramatical.
3. `sessionStorage` bloqueado (modo privado / iframes): el sitio no rompe; las respuestas viven en memoria.
4. Recarga a mitad de página: las respuestas persisten en la sesión y los botones las muestran seleccionadas.
5. Mobile 390 px con reduced-motion: ninguna sección queda con opacidad 0 ni contenido oculto por animaciones que no corren.
